# Samaki Fresh — FastCart Ecommerce (Template)

This repository contains the Samaki Fresh Django ecommerce template (FastCart fork).

- Demo (GitHub Pages template): https://walterjesse.github.io/samakifresh/

Notes:
- This repo contains project source files but not production media/static blobs (`venv/`, `staticfiles/`, and `media/` are excluded in `.gitignore`).
- Configure environment variables using `.env` in your deployment environment. Do not commit secrets.
